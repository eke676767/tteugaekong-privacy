1. 개요

Fizz Works(이하 “운영자”)는 뜨개콩의 개인정보 처리 내용을 안내합니다. 뜨개콩은 작품과 카운터의 단수를 기록하는 앱입니다. 회원가입·로그인, 운영자가 작품 기록을 보관하는 자체 서버 및 자체 클라우드 동기화 기능은 없습니다.

기기의 기록, Google 광고·동의 서비스의 처리, Android 자동 백업은 서로 다른 경로입니다. 자체 서버가 없다는 것이 모든 외부 통신이나 SDK의 데이터 처리가 없다는 뜻은 아닙니다.

2. 기기에 저장하는 데이터와 목적

  • 작품·카운터 이름, 내부 식별자, 생성·수정 시각: 작품과 카운터 구분 및 관리
  • 현재 단수, 목표 단수, 카운터 순서: 기록과 진행률 표시
  • 마지막 선택 카운터: 선택 상태 복원
  • 화면 꺼짐 방지·버튼 진동 설정: 사용자 설정 유지

이 기록은 앱 전용 SQLite 데이터베이스에 저장됩니다. 현재 앱에는 이 기록을 운영자 서버에 업로드하거나 작품 이름·단수·목표를 광고 요청에 별도로 전달하는 기능이 없습니다. 이름 입력란에 불필요한 개인정보를 포함하지 마세요. 과거 버전 호환을 위한 기록이 데이터베이스에 남아 있을 수 있으며 해당 작품 삭제와 앱 데이터 초기화의 적용을 받습니다.

3. Google AdMob 광고

뜨개콩은 Google AdMob 광고 SDK를 사용합니다. Google은 기본 처리 항목으로 IP 주소, 광고·앱 상호작용, 성능·진단 정보, Android 광고 ID·앱 세트 ID 등 기기 및 계정 관련 식별자를 안내합니다. IP 주소로 대략적인 위치를 추정할 수 있습니다. 이러한 정보는 광고 제공·측정, 분석, 부정행위 방지 등에 사용됩니다. 앱이 모든 항목을 직접 조회·저장한다는 뜻은 아니며 실제 처리 범위는 기기 설정·동의 상태·SDK 구성에 따라 달라질 수 있습니다.

현재 앱은 비개인화 광고를 요청합니다. 비개인화 광고도 식별자와 모든 데이터 처리를 배제하지 않습니다. 별도로 연동한 사용자 행동 분석 SDK는 없지만 광고 SDK 자체의 측정·분석 처리는 별개입니다.

Google 광고 SDK 데이터 처리 안내 · 비개인화 광고 안내

4. Google UMP와 개인정보 선택

Google UMP는 동의 정보를 갱신하고 필요한 지역·상태에서 선택 화면을 제공합니다. 앱은 광고 요청 가능 상태를 확인한 후 광고 SDK를 초기화하고 광고를 요청합니다. 동의 정보 갱신 과정에도 Google과의 통신이 발생할 수 있습니다. 광고 요청 가능 상태가 모든 목적에 대한 전면 동의를 의미하지는 않습니다.

선택 변경 진입점이 필요한 경우 광고 영역에 “광고 개인정보 설정”이 표시됩니다. 해당 화면에서 제공되는 선택을 변경할 수 있습니다. 기기의 광고 관련 설정에서도 광고 ID 제어 기능을 확인할 수 있습니다. 선택 변경이 이미 처리된 Google 서버 기록의 전체 삭제를 의미하지는 않습니다. Google UMP 안내

5. 보유기간과 삭제

기기 내 기록에는 별도의 자동 만료기간이 없습니다. 사용자가 삭제하거나 앱 데이터를 초기화하기 전까지 보관될 수 있습니다.

  • 작품 메뉴에서 삭제를 확인하면 해당 작품과 소속 카운터가 삭제됩니다.
  • 카운터 메뉴에서 개별 카운터를 삭제할 수 있습니다. 마지막 카운터는 작품 삭제로 함께 제거할 수 있습니다.
  • Android 앱 정보의 저장공간에서 앱 데이터를 삭제할 수 있습니다. 경로와 명칭은 기기에 따라 다릅니다.
  • 앱 제거는 일반적으로 로컬 데이터를 제거하지만 OS 백업 사본과 Google 측 기록까지 삭제하지는 않습니다. 과거 백업이 복원되면 이전 기록이 다시 나타날 수 있습니다.

앱 내 삭제는 논리적인 기록 삭제이며 저장 매체의 즉시 복구 불가능한 삭제를 보장하지 않습니다. Google이 처리한 정보의 보관·삭제에는 Google의 정책과 이용자 설정이 적용됩니다. 운영자는 Google 서버 또는 OS 백업의 모든 사본을 앱 내 삭제로 제거하는 기능을 제공하지 않습니다.

뜨개콩은 Android 자동 백업을 유지합니다. 기기와 운영체제 설정에 따라 작품·카운터·설정 기록이 클라우드에 백업되거나 다른 기기로 이전될 수 있습니다. 클라우드 백업은 백업 제공자가 사본을 보관하는 경로이며, 기기 간 이전은 새 기기 설정 과정의 별도 전송 경로일 수 있습니다. 앱 자체 서버 동기화와는 다릅니다.

사용 가능한 백업 사본, 사용자 계정과 복원 선택, 앱 식별자·서명·버전 호환, OS·제조사 조건에 따라 재설치 또는 기기 변경 시 기록이 복원될 수 있습니다. 백업 실행, 최신 기록 포함 및 복원을 보장하지 않습니다. 기기의 백업 설정에서 사용 여부와 관리 방법을 확인하세요. 앱 삭제만으로 백업 사본이 즉시 삭제되는 것은 아닙니다. Android 자동 백업 안내
